CE QUE L'IMAGE GARANTIT

Une image, six promesses.
Vérifiées, pas décoratives.

01 / NON-ROOT

uid 101, jamais root

nginx et ses workers tournent en utilisateur dédié nginx (uid 101), verrouillé par un USER explicit dans le Dockerfile.

02 / MULTI-STAGE

Node au build, nginx au runtime

Le site est compilé dans un stage node:22-alpine, puis seul le dossier build/ traverse dans l'image finale.

03 / IMAGE LÉGÈRE

Alpine, sans Node au runtime

Base nginx-unprivileged:1.27-alpine : pas de Node, pas d'outils de build, ~150 Mo tout compris avec la vidéo de fond.

04 / SANS SECRETS

secrets/ exclu du contexte

Le dossier secrets/ est ignoré par Git et exclu par .dockerignore : un find *password* dans le conteneur ne renvoie rien.

05 / HEALTHCHECK

Surveillé toutes les 30 s

Le Dockerfile déclare un HEALTHCHECK sur /healthz que le conteneur passe : status healthy dès le démarrage.

06 / SCAN TRIVY

CI bloquant sur HIGH + CRITICAL

La CI scanne l'image avec aquasecurity/trivy-action, exit-code 1. Après remédiation : 0 vulnérabilité.
